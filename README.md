# Yummy Recipes – Interactive Online Recipe & Ordering Website
# Overview
Yummy Recipes is a modern, interactive, and fully responsive recipe website that lets users discover delicious recipes and order them directly. It offers user-friendly modals, a recipe preview system, a dynamic cart, and search functionality with localStorage-based favorites and orders.

# Key Features
✅ Full-screen hero section with a recipe search bar

✅ Sticky navbar with smooth navigation to sections: Home, Recipes, Reviews, Contact, About

✅ Recipe cards with images, descriptions, prices, and a "View Recipe" modal

✅ Favorite button to save preferred recipes (saved in localStorage)

✅ Cart modal with item count, total amount, and simulated checkout system

✅ Login/Signup modals for user authentication simulation

✅ User reviews section with styled testimonials

✅ Query form to ask questions (with validation)

✅ Tailwind CSS integrated for sleek and responsive design

✅ Responsive layout, transitions, and hover effects for smooth UX

# Technologies Used
HTML5 — page structure

CSS3 — custom styles and layout enhancements

Tailwind CSS (via CDN) — responsive utility-first styling

Vanilla JavaScript — interactivity, localStorage handling, form validation

Unsplash Images — for visually appealing recipes

Font Awesome (optional) — for icons (e.g., stars, hearts)
